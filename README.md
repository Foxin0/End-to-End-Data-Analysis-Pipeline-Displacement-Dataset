# End-to-End Data Analysis Pipeline: Displacement Dataset

An end-to-end data analysis pipeline built with Python as part of the Digital Egypt Pioneers Initiative (DEPI) under the supervision of Eng. Eman Ghanem. 

## 📊 Project Overview
This project takes raw humanitarian displacement data and processes it through a complete data analysis lifecycle, covering cleaning, feature engineering, statistical analysis, and machine learning preprocessing across multiple conflict-affected regions (Iraq, Libya, Syria, and Yemen).

---

## 🛠️ Tech Stack & Libraries
* **Python**
* **Pandas & NumPy:** For data loading, manipulation, and numerical operations.
* **Scikit-Learn:** For feature scaling and outlier detection/flagging.
* **Matplotlib & Seaborn:** For exploratory and statistical data visualization.

---

## 🔄 Workflow Steps
1. **Data Loading & Exploration:** Inspected and explored raw data using Pandas.
2. **Data Cleaning:** Handled missing values, corrected formats, and cleaned date fields.
3. **Feature Engineering:** Created derived metrics including gender percentages, average people per household, and dominant housing types.
4. **Aggregation:** Summarized metrics by country and year using pivot tables and grouping.
5. **Preprocessing & Outliers:** Applied feature scaling and flagged statistical anomalies using Scikit-Learn.
6. **Data Visualization:** Generated bar charts, trend lines, distributions, and correlation matrices using Matplotlib and Seaborn.

---

## 💡 Key Takeaways
Every step in this pipeline reinforced that rigorous data cleaning and feature engineering are just as foundational and vital as the final visual charts.
